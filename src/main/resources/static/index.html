⚡ Core Invariants

Demonstrated in university technical defense:

  • Dijkstra's Lock Ordering: Ascending SKU sort prevents multi-item checkouts from deadlocking.
  • Zero Overselling: reserved <= on_hand enforced via DB check constraints.
  • Idempotency: SHA-256 request hashing prevents mobile duplicate orders.
  • Non-Blocking Gateway: Zero open transactions during payment I/O.
